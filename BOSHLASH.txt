 ISHGA TUSHIRISH
-----------------------------------------------------------------------

 1. Bu papkani PyCharm'da oching:
       File -> Open -> shu papkani tanlang -> OK
    (Faylni emas, PAPKANI oching.)

 2. Avval namunani ishga tushiring:
       python namuna.py

 3. topshiriqlar.py faylini oching.

 4. Yuqoridagi  TOPSHIRIQ = 1  qatorida raqamni oʻzgartiring
    (1 dan 8 gacha).

 5. Ctrl+S bosing, soʻng yashil Run tugmasini bosing.

 Talab: Python 3.8 yoki undan yangisi.
 Kutubxona oʻrnatish KERAK EMAS. Internet ham kerak emas.
